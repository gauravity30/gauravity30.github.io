# Memory and Network Commands
*Created on:* 2025-01-29  
*Tags:* #Memory #Network #Commands
*Course:* [[HPC]]

---
## Memory Commands

- Display memory usage - *free*
- Report virtual memory statistics - *vmstat*
- Information about disk space usage on the system - *df*
- Show or enable/disable swap space - *swapon*
- Show detailed memory information - *meminfo*

## Network Commands

- Network Interface:
	- Loopback Interface: A virtual interface used for local communication within the system.
	- Physical Interfaces: These include Ethernet and Wi-Fi interfaces.
- Test network connectivity to a host - *ping*
- Show/manipulate routing, devices, policy routing - *ip*
- Secure Shell for remote login and command execution - *ssh*
- Retrieve/Download files from the web - *wget*
- Secure copy between hosts - *scp*
