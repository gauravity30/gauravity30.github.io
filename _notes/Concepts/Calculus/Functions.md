## Definition
A function from a set D to a set Y is a rule that assigns a unique element $f(x) \in Y$ to each element $x \in D$.

The set $D$ of all possible input values is called the *domain*, whereas the set of all values of $f(x)$ as $x$ varies throughout $D$ is called the *range* of the function.


*A function $f$ can have only one value of $f(x)$ for each $x$ in its domain.*
