# Basics of Pointwise
*Created on:* 2024-12-23  
*Tags:* #Pointwise #Meshing
*Course:* [[Pointwise]]

---
## Definition

- Database --> Geometry
- Database Mask: To select only database mask
- Grid Curve --> Connectors
- Number of points on the connector is its Dimension
- Spacing constraint on the start and end of the connectors affect the distribution.
- 2D Surface Mesh --> Domain
- Volume Mesh --> Block

Create --> Extrude --> Normal: Creates a 2D extrusion.

Select Solvers and Boundary Conditions through **CAE** menu.

Export to mesh for different solvers.
## Shortcuts

- Pan: Shift + RMB
- Zoom: Scroll Wheel
- Zoom Box: Shift + MMB
- Reset: Ctrl + R
- Zoom to Fit: F2
- Rotation: Ctrl + RMB
- Inclusive Selection: Shift + LMB
- Cycle between selectable entities: Spacebar
